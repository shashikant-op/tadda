# AI Course Generation Pipeline - Phase 1

Self-contained Phase 1 implementation for autonomous AI course generation.

## Features
- Course generation job management and status tracking
- Web research provider abstraction and source ranking
- AI curriculum and structure generation (Topics & Subtopics)
- Structured educational content generator
- Visual/diagram prompt generator
- Deterministic content validation and quality control
- Persistence via existing backend APIs (`/api/v1/branches`, `/api/v1/subjects`, `/api/v1/topics`, `/api/v1/tutorials`)
- Admin testing interface and comprehensive test suite (Unit, Integration, E2E)
